# Agent Usage Policy

This repository (the "Capstone System") is intended to be developed and maintained using **Claude Code** (Anthropic's CLI agent) as the primary development assistant. While the code itself is open for inspection, the following guidelines apply to the use of automated agents or language models with this codebase:

## Intended Use
- Development, debugging, and feature implementation using Claude Code.
- Educational purposes, demonstrations, and portfolio showcases.
- Collaboration with human developers where Claude Code acts as a pair‑programming assistant.

## Prohibited Uses
- Using this repository to train, fine‑tune, or evaluate **competing** language models or agents without explicit permission.
- Deploying automated agents that attempt to extract, replicate, or reverse‑engineer, or otherwise exploit the codebase for commercial AI training datasets.
- Running unauthorized agents that modify the repository in ways that bypass project contribution guidelines (e.g., bypassing code review, automated pull‑request spam).

## Enforcement
These guidelines are expressed in good faith. Violations may result in:
- Revocation of any granted access to private repositories or credentials.
- Requests to remove infringing content from public platforms.
- Legal action if misuse violates applicable laws (e.g., copyright, anti‑circumvention provisions).

## Questions?
If you are unsure whether a particular use of an automated agent is permitted, please open an issue or contact the repository maintainer before proceeding.
